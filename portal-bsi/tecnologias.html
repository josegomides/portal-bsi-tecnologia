Tecnologias

A stack web

Toda página web é construída sobre três camadas: o HTML define a estrutura e o conteúdo, o CSS define a aparência e o JavaScript define o comportamento. Nesta página reunimos as tecnologias que estudamos no curso, com os conceitos principais de cada uma, como um guia de referência para a turma.

Tecnologias estudadas

HTML

Linguagem de marcação que organiza o conteúdo da página. Serve para dizer ao navegador o que cada parte é: título, parágrafo, lista, tabela, navegação.

Tag
Marcação entre sinais de menor e maior que delimita um elemento, como <p> e </p>.
Atributo
Informação extra dentro da tag de abertura, como href em um link ou alt em uma imagem.
Semântica
Uso da tag que descreve o significado do conteúdo, como header, nav e article, em vez de div.

CSS

Linguagem de estilo que controla a aparência da página. Serve para definir cores, fontes, espaçamentos e posicionamento dos elementos.

Seletor
Parte da regra que indica quais elementos recebem o estilo, como .classe, #id ou uma tag.
Especificidade
Critério que decide qual regra vence quando duas se aplicam ao mesmo elemento.
Box model
Modelo em que todo elemento é uma caixa formada por conteúdo, padding, border e margin.

JavaScript

Linguagem de programação que roda no navegador. Serve para adicionar interatividade: responder a cliques, validar formulários e alterar a página sem recarregar.

Variável
Espaço nomeado que guarda um valor para ser usado depois no código.
Função
Bloco de código reutilizável que executa uma tarefa quando é chamado.
Evento
Ação do usuário ou do navegador, como um clique, que o código pode detectar e tratar.

Git

Sistema de controle de versão. Serve para registrar o histórico do projeto e permitir que várias pessoas trabalhem no mesmo código sem perder alterações.

Repositório
Pasta do projeto acompanhada pelo Git, com todo o histórico de alterações.
Commit
Registro de um conjunto de alterações, com uma mensagem que descreve o que mudou.
Push
Envio dos commits locais para o repositório remoto, como o GitHub.

HTML vs CSS vs JavaScript

Comparação entre as três tecnologias da camada front-end
Tecnologia Responsabilidade Linguagem Quando usar
HTML Estrutura e conteúdo da página De marcação Sempre: é a base de qualquer página web
CSS Aparência: cores, fontes, espaçamento e layout De estilo Para dar identidade visual e organizar a disposição dos elementos
JavaScript Comportamento e interatividade De programação Quando a página precisa reagir a ações do usuário ou mudar sem recarregar
